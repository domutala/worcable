This guide explains how to **configure, launch, and manage the Worcable ecosystem** using Docker.

Worcable is composed of multiple services:

- **Nuxt Application (Fullstack)** → Includes both Frontend and Backend
- **Database** (MongoDB)
- **CV Parser** (Python)

## Prerequisites

Make sure the following tools are installed:

- **Docker** ≥ 20.10  
- **Docker Compose** ≥ 2.0  

Verify installation:

```bash
docker -v
docker compose version
```

## Clone the project

```bash
git clone https://github.com/domutala/worcable.git
cd worcable
```

## Configure environment variables

Create a `.env` file at the root:

```bash
cp .env.example .env
```

Example configuration:

```env
PORT=3000
DATABASE_PORT=27017
CV_PARSER_PORT=5000
```

## Using the Launch Script

A helper script is available to simplify Docker usage:

```
deploy/run.sh
```

### Initialization

Make the script executable:

```bash
chmod +x deploy/run.sh
```

### Start services

By default, all services are started:

```bash
./deploy/run.sh
```

### Available modes

You can control which services to run using `--project`:

| Mode              | Command                            | Description                                    |
| ----------------- | ---------------------------------- | ---------------------------------------------- |
| **All (default)** | `./deploy/run.sh`                  | Runs Nuxt (fullstack), Database, and CV Parser |
| **Database only** | `./deploy/run.sh --project db`     | Runs Nuxt (fullstack) + Database               |
| **Parser mode**   | `./deploy/run.sh --project parser` | Runs Nuxt (fullstack) + CV Parser              |
| **Frontend only** | `./deploy/run.sh --project base`   | Runs Nuxt only                                 |

## Default Access URLs

Once started:

| Service                 | URL                                            |
| ----------------------- | ---------------------------------------------- |
| Nuxt App (UI + API) | [http://localhost:3000](http://localhost:3000) |
| Database            | mongodb://localhost:27017                      |
| CV Parser            | [http://localhost:5000](http://localhost:5000) |

## Build & Updates

The script automatically rebuilds containers:

```bash
docker compose up --build
```

Changes applied on restart:

* Nuxt (UI + server)
* CV Parser (Python)

## Stop all services

```bash
./deploy/run.sh --stop
```

## View logs

```bash
./deploy/run.sh --logs
```

## Clean restart

```bash
docker compose down -v
docker system prune -f
./deploy/run.sh
```

## Production Tips

* Use a reverse proxy (NGINX / Traefik)
* Secure environment variables
* Do not expose database publicly
* Enable HTTPS (Let's Encrypt)

## Summary

Worcable leverages Docker to provide:

* Fast setup
* Reproducible environments
* Modular services
* Fullstack Nuxt architecture (UI + API)
