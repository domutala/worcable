This documentation details the procedure to configure and launch the **Worcable** ecosystem using Docker.


## Prerequisites

Ensure the following tools are installed on your machine:

* **Docker** (v20.10 or higher)
* **Docker Compose** (v2.0 or higher)


## Using the Launch Script

A `run.sh` script is located in the `deploy/` folder to automate Docker profile management.

### Initialization
Grant execution permissions to the script:
```bash
chmod +x deploy/run.sh
```

### Main Commands

The script accepts the `--project` parameter to define the launch scope. Default is `all`.

| Command | Description |
| :--- | :--- |
| `./deploy/run.sh` | Launches all services (Nuxt, Database, CV Parser). |
| `./deploy/run.sh --project db` | Launches Nuxt and Database. |
| `./deploy/run.sh --project parser` | Launches Nuxt and the CV Parser. |
| `./deploy/run.sh --project base` | Launches Nuxt only. |

### Stopping and Logs

| Action | Command |
| :--- | :--- |
| **Stop** | `./deploy/run.sh --stop` |
| **Logs** | `./deploy/run.sh --logs` |

## Technical Configuration

### Customizing Ports
You can change the default ports by creating a `.env` file at the root of the project:

```env
PORT=8080
DATABASE_URL=27018
CV_PARSER_PORT=5001
```

### Default Network Access
By default, services are exposed as follows:
* **Nuxt Frontend**: `http://localhost:3000`
* **Database**: `localhost:27017`
* **CV Parser**: `localhost:5000`

### Build and Updates
The `run.sh` script automatically includes the `--build` flag. Any changes to the source code (Nuxt or Python) will be applied upon restart.
